KHUSHI'S BIRTHDAY WEBSITE 💗

Files:
- index.html: website content
- style.css: colors, layout, animations
- script.js: surprise popup and celebration
- assets/khushi-photo.png: original portrait
- assets/khushi-birthday-poster.png: birthday poster

HOW TO OPEN:
1. Extract the ZIP.
2. Open the khushi_birthday_website folder.
3. Double-click index.html (internet helps load the decorative fonts).

HOW TO HOST FREE ON GITHUB PAGES:
1. Sign in to GitHub and create a new public repository, e.g. khushi-birthday.
2. Upload all files and the assets folder (upload the contents of this folder, not the ZIP itself).
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait a minute or two; GitHub will show your website URL under Pages.

To change text, edit index.html. Keep image filenames the same if replacing photos.
